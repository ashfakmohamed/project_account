# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email **ashfakmohamed66@gmail.com** with the repository name, affected component, reproduction steps, and expected impact. Do not include real customer, employer, or production data.

You will receive an acknowledgement after the report is reviewed. A fix and disclosure timeline will depend on severity and reproducibility.

## Supported code

The latest version on the `main` branch is the supported development version. Older commits and archived learning repositories are not maintained.
